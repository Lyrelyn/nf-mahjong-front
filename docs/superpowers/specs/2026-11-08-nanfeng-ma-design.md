# 南丰麻将 · 买码（第 5 人）设计

- 范围：单机对局加一个**可选的第 5 个参与者「买码位」**。4 个打牌座位不变，买码位由 AI 坐，局末结算。
- 规则权威：`nf-mahjong/docs/rules-confirmed.md` 的 R-09（原先"未确认、留到 V1.1"）。
  本设计即 R-09 的确认结果，按产品决定从 V1.1 提前到一期（见 §8 的偏差记录）。
- 参考实现：`F:\projects\nf-mahjong-backend\app\core\nanfeng\ma.py` + `score/settle.py` 的买码段
  + `tests/nanfeng/test_ma.py`（后端已有完整实现与 12 条用例）。前端移植同一口径。

## 1. 确认口径（用户 2026-11 口头确认）

| 项 | 口径 |
|---|---|
| 谁买码 | **5 人轮换**（R-02）：每局 4 人打、1 人轮空买码。轮空者由"点炮者 / 自摸者的对家 / 荒庄的庄家"决定，上局的买码者回来接管那把椅子。单机名册 = 你 + 4 个 AI，**你也会轮空** |
| 张数 | `0 / 1 / 2 / 4`，默认 0（不买码） |
| 码牌来源 | 洗牌后**牌墙末尾** N 张留作码牌，不参与发牌、不参与摸牌 → 本局牌墙少 N 张、荒庄提前 N 张 |
| 何时翻开 | 局中**不公开**（谁也不知道买的是谁），**局末结算时**按顺序翻开 |
| 指向谁 | 每张码牌按**点数**指向相对庄家的座位：`(点数 − 1) % 4`（0 庄家 / 1 下家 / 2 对家 / 3 上家）。字牌用自己的点数：东南西北 1..4、中发白 1..3 |
| 怎么算分 | 买码位**复制被指向座位本局的每一笔现金流**：那家收多少买家也收多少（同样的付款方出），那家付多少买家也付多少。**双向**，不是只跟赢 |
| 多张 | 指向同一家 → 叠加（买两份就是跟着下两倍注）；指向不同家 → 各算各的，可能互相抵消 |
| 零和 | 五家零和：`Σ(四家本局 deltas) + 买码位本局净额 = 0`，硬校验 |

例（用户给的口径）：码牌两张都指庄家、庄家自摸 1 炮 → 庄家 `+3`，买码位再从三家各收 2（共 `+6`，即"收两遍"），
三家各 `-3`；五家合计 0。

## 2. 为什么是"复制现金流"而不是"复制净得分"

两者只在**不对称收支**上不同：明杠（直杠）只由点杠者付，补杠/暗杠三家各付。若按净得分复制，
"码指庄家、庄家开了一个明杠"这种情形会算错（净额里含着只由某一家付的 2 分）。
按笔复制才符合"跟着被买的人走"的口径，且天然让多张叠加/不同座位抵消成立。

## 3. 数据模型

```
RuleConfig.buyCode: { count: 0 | 1 | 2 | 4 }      // 原 { enabled: boolean }
GameState:
  maTiles: Tile[]          // 本局预留的码牌（局中不公开）
  maScore: number          // 买码位**跨局累计**净得分
  roundGangFlows: GangFlow[]  // 本局杠分现金流 {(payer, payee, amount)}，与 roundGangScore 同源写入
SettleResult:
  deltas: number[]         // 四家本局净得分（**已含**买码带来的额外收付）
  detail: FanDetail[]
  maDelta: number          // 买码位本局净额
  maDetail: MaDetail[]     // 每张码牌 { tile, seat, delta }
```

- 买码位**不是** `GameState.seats` 里的一员，不参与 `nextRoundSeating`、不占座位、不轮换。
- 每局开局时 `scores`/`roundGangScore` 归零沿用现有逻辑；`maScore` 跨局累计，只在结算时 `+= maDelta`。
- 码牌复用真实牌码（洗牌结果里的牌），**不用** 61+ 预留码位。

## 4. 结算与不变量

1. 先算出本局全部现金流 `flows`：荒庄 = 庄家赔每家；自摸 = 其余三家各付；点炮 = 放炮者付给每个赢家；
   再加上本局杠分流水 `roundGangFlows`。
2. 对每张码牌：把"与该座位相关的每一笔"复制一份给买码位 —— 付款方是他 → 买家付同一张；收款方是他 → 买家收同一张。
   逐笔落到 `deltas`（四家多收/多付）与 `maDelta`（买家净额），并记 `maDetail`。
3. 硬校验 `Σdeltas + maDelta === 0`，不满足直接抛异常（不静默修正）。
4. `state/invariants.ts`：
   - 牌张守恒把 `maTiles.length` 算进去（`牌墙 + 暗牌副露 + 牌河 + 码牌 = 136`）；
   - 零和改为 `Σ scores + Σ roundGangScore + maScore === 0`。

## 5. 运行时与快照

- `NanfengMatch` 仍只有 4 个座位；`cfg` 里带 `buyCode.count`。不新增 AI 决策（买码位不做任何选择）。
- 快照新增：

```
ma: {
  count: number          // 本局买了几张（0 = 没买码）
  tiles: Tile[] | null   // 局中 null；round-over 后是翻开的码牌
  detail: MaDetail[]     // 每张的指向与收付（round-over 后）
  delta: number          // 本局净额（round-over 后）
  score: number          // 累计买码分
}
```

- `wallHeadDrawn` 必须**不把预留的码牌算成已摸走**：`136 − maCount − (wall.length − wallPos)`。
  否则 3D 牌墙会从牌头多抽 N 张，正好是之前"摸这边、少那边"那类错位。

## 6. 界面

- 入口 `NanfengApp.vue`：`?ma=0|1|2|4` 直接开局；不带参时先给一个极简开局面板（不买码 / 买 1 / 2 / 4 张）。
- 买码席卡片（`NanfengTable.vue` 内绝对定位，浮在右上角，**不动 HUD 的 4 座布局**）：
  中性徽章（不新增莲花类素材）+「买码（AI）」+ 局中 N 张**反面**牌（正好解释牌墙少 N 张）+ 本局张数 + 累计分；
  局末翻面，每张显示牌面 → 指向（庄家/下家/对家/上家）→ 该张 `±分`。
- 结算面板：四家 deltas 之后加一行「买码位 +X · 累计 Y」，并列出每张码牌。荒庄同样显示（码指庄家 → 买家跟着赔）。

## 8. 明确不做（及偏差记录）

## 9. 5 人换座与观战视角（2026-11 追加）

用户追加要求："加入 5 人换座"、"可以点击头像选择跟这个人视角同步"。落地方式：

- `NanfengMatch` 增加 `buyerId`：给了就每局按 `nextRoundSeating()` 的 `sittingOut` 换人，
  上局的买码者接管那把椅子（**座位位置与顺序不变**，所以 `dealer` 这类下标继续有效）。
  名册第一人是真人，靠名字在座位表里定位自己 —— 找不到就说明这局轮空。
- 轮空那一局 `snapshot.humanSeat === -1`：不能出牌，AI 把四家打完；
  `setViewSeat(seat)` 可以切视角，`projectToTable` 把 `players` 重排成"本家视角"
  （`players[0]` = 当前视角座位，其余下标全部是相对座位）。
- 视角座位也是"手牌区"那一家：切到谁，屏幕下方就显示谁的手牌、牌桌与牌墙开口也跟着转。
  在桌上时视角锁死在自己座位上（`setViewSeat` 直接忽略），避免看到别人的手牌。
- 界面入口：`NanfengApp` 先选「5 人轮换 / 4 人局」+「买码张数」，`?players=5&ma=2` 可直接开局。
